# 评测：怎么证明「真的会说四川话」

方言 TTS 没有公认的客观指标。任何单一数字都能被反驳，所以本仓库用**多条互相独立的证据**
交叉验证，每条都能单独证伪结论；同时把**失败的指标**也记录下来，避免下次重复踩坑。

所有数字来自 `results/` 下的原始 JSON，可复算。

## 0. 评测集与口径

| 集合 | 来源 | 条数 | 用途 |
|---|---|---|---|
| KeSpeech Southwestern | KeSpeech test split，四川话母语者 | 400 | 方言主指标（训练时已剔除） |
| KeSpeech Mandarin | 同 corpus、同录制通道的普通话 | 300 | 遗忘守卫 |
| 真实四川话锚点 | MagicHub/xiNan 真人录音 | 40 | 声学参照带 |
| 真实普通话锚点 | KeSpeech Mandarin 真人录音 | 40 | 声学参照带 |
| 合成川话文本 | 手写成都口语（模型没见过） | 20 | TTS 可懂度 |

三条口径纪律：

1. **ASR 一律 `use_itn=False`**。ITN 会把「七千多种」规范成「7000多种」，如果基线开 ITN、
   微调版不开，基线的 CER 会被系统性抬高——这是第一轮评测踩过的坑，详见 §5。
2. **同一 vocoder 内比较**。所有 TTS 对照都用 CosyVoice2 自带的 flow + HiFi-GAN，只换 LLM
   和说话人向量，避免声码器差异混进结论。
3. **评测集与训练集不相交**。400 条川话、300 条普通话在构建 manifest 时按 utt id 显式剔除。

> 方法学妥协：KeSpeech 官方只公开 test split，所以训练也用了 test split 的另一部分。
> 两边按 utt id 严格不相交，但严格说不是官方 train/test 划分。

## 1. ASR：唯一的硬指标

`results/asr_report.json`。CER 越低越好，两个方向都要看。

| 检查点 | 西南官话 CER（400 条） | 普通话 CER（300 条） |
|---|---|---|
| 基线 SenseVoiceSmall | 0.1078 | 0.0384 |
| epoch 0 | 0.0913 | 0.0354 |
| epoch 1 | 0.0864 | 0.0345 |
| **epoch 2（选用）** | **0.0852** | **0.0340** |
| epoch 3 | 0.0854 | 0.0340 |

- 西南官话：**−21.0% 相对**（0.1078 → 0.0852）
- 普通话：**−11.5% 相对**（0.0384 → 0.0340）

普通话不但没退化还一起降了。原因有两个：训练集里按 18% 混了普通话回放（THCHS-30 900 条），
以及留出集是**跨说话人**的——不是把训练见过的句子换个说法考一遍。

这是本次交付最硬的一条证据：同一个识别器、同一批音频、同一套解码参数，只在方言数据上
微调过，川话和普通话都变好。

## 2. TTS：同一句文本的三方对照（最强证据）

`results/tts_eval.json` + `samples/`。文本是「今天天气好安逸哦，我们出去耍一哈嘛。」
——手写句，训练语料里不存在。

| 音频 | 普通话 ASR 回读 | 川话 ASR 回读 | CER(base) | CER(ft) |
|---|---|---|---|---|
| 原版模型 + 普通话提示音 | 今天天气好**哎哟**我们出去耍**一下**嘛 | 今天天气好哎呦我们出去耍一哈嘛 | 0.250 | 0.188 |
| 原版模型 + 川话提示音（零样本克隆） | 今天天气好**哎哟**我们出去耍**一下**嘛 | 今天天气好哎哟，我们出去耍一哈嘛 | 0.250 | 0.188 |
| **SFT 模型（sichuan_female）** | 今天天气好安逸哦我们出去耍一哈嘛 | 今天天气好安逸哦，我们出去耍一哈嘛。 | **0.000** | **0.000** |

原版模型把「安逸」读成「哎哟」、「一哈」读成「一下」——**读错字**，不是口音差异：
原版模型没见过川话口语词。微调模型两个识别器都 0 错。

这是效果最直接的证据：**同一句话，原版 25% 字错，微调 0% 字错。**

### 2.1 自发的方言泛化

`sft_avg_02.wav` 的文本是「他屋头**那个**猫儿又跑到房顶上去了」，普通话识别器如实回读成
「他屋头**嘞个**猫儿又跑到房顶上去了」——模型把「那个」读成了成都话的「嘞个」。
这是训练数据里出现过的方言特征，模型把它泛化到了没见过的句子上；川话识别器因为见过这种
读法，反而把它规范化回了「那个」。

### 2.2 20 句批量结果（固定随机种子）

`results/tts_epoch_sweep.json`。用固定种子逐句生成，比较每个检查点：

| 检查点 | 普通话 ASR CER | 川话 ASR CER | 音节/秒 | 平均时长 |
|---|---|---|---|---|
| 原版 LLM（同一说话人向量） | 0.0552 | 0.0310 | 5.29 | 3.36 s |
| epoch 0 | 0.0621 | 0.0483 | 5.25 | 2.87 s |
| epoch 1 | 0.0690 | 0.0483 | 5.31 | 2.91 s |
| **epoch 2** | **0.0379** | **0.0276** | 5.21 | 2.88 s |
| epoch 3 | 0.0655 | 0.0448 | 5.30 | 2.93 s |
| **epoch 4（选用）** | **0.0483** | **0.0345** | 5.40 | 2.82 s |
| epoch 5 | 0.0552 | 0.0552 | 5.03 | 2.86 s |
| epoch 6 | 0.0621 | 0.0448 | 5.20 | 2.74 s |
| epoch 7 | 0.0586 | 0.0448 | 5.55 | 2.76 s |
| epoch 8 | 0.0655 | 0.0517 | 5.25 | 2.75 s |

读法：

- **所有 SFT 检查点的普通话 CER 都不高于原版**（0.038–0.069 vs 0.055），说明微调没有让
  读音变差，反而整体更准。
- 逐 epoch 的差异不单调，量级（0.01–0.03）≈ 2–5 个字，属于 20 句样本下的采样噪声。
  所以**用 CER 选不出"口音最浓"的检查点**——这一点必须诚实说明。
- 最终选 epoch 4 是因为它的**验证集 CV loss 最低**（3.4716，见 `docs/training.md`），
  而不是因为 CER 最好；epoch 2 的 CER 更漂亮但 CV 更高。

### 2.3 口音强度校准到真人

| 音频 | 普通话 ASR CER |
|---|---|
| 真人普通话（40 条锚点） | 0.0297 |
| 原版模型标准朗读（10 句） | 0.0612 |
| **SFT 合成川话（10 句）** | **0.0748** |
| **真人四川话（40 条锚点）** | **0.0767** |
| 零样本克隆（崩） | 0.1497 |

合成川话让普通话识别器产生的偏离量（0.0748）与真人四川话录音（0.0767）几乎相同。
这是「口音强度对标真人」的参照证据，不是严格配对实验（文本不同）。

### 2.4 声学统计

| 音频 | 音节/秒 | F0 中位（半音，相对 100 Hz） |
|---|---|---|
| 真人四川话锚点 | 4.67 | 14.44 |
| 真人普通话锚点 | 3.72 | 4.70 |
| 原版 + 普通话提示音 | 5.37 | 17.42 |
| 原版 + 川话提示音 | 4.65 | 14.70 |
| SFT（sichuan_female） | 5.16 | 16.59 |
| SFT（sichuan_avg） | 4.72 | 15.40 |

`sichuan_avg` 的音节速率 4.72 与真人川话 4.67 基本重合。**F0 中位数不能跨说话人比较**：
川话锚点是女声（~230 Hz），普通话锚点是混合性别（~131 Hz），差值主要来自音高而非方言，
所以这一列只作组内参考，不作方言判据。

### 2.5 音色保真度

`results/speaker_sim.json`，campplus 说话人向量余弦：

| 声音 | 平均余弦 | 最小余弦 |
|---|---|---|
| sichuan_female | **0.678** | 0.557 |
| sichuan_avg | 0.369 | 0.165 |

`sichuan_female` 的 0.678 说明合成音频确实带着目标说话人的音色；`sichuan_avg` 是 2233 条
川话说话人向量的均值，均值向量天然不对应任何真实说话人，相似度低是预期的。因此**默认声音
用 `sichuan_female`**。

### 2.6 交叉 ASR：信号太弱，不作为结论

最初的设想是「普通话识别器 CER 高、川话识别器 CER 低 = 真口音；两者都高 = 崩了」。
10 句的结果（`results/cross_asr.json`）：

| 合成集 | 普通话 ASR CER | 川话 ASR CER | 相对改善 |
|---|---|---|---|
| 原版 + 普通话提示音 | 0.0680 | 0.0544 | −20.0% |
| 原版 + 川话提示音 | 0.1497 | 0.1565 | **+4.5%**（更差） |
| SFT 模型 | 0.0748 | 0.0544 | −27.3% |

这个结果方向是对的（零样本克隆的音频川话识别器也救不回来 → 确实崩了），但**幅度太小**，
且川话识别器本身在所有音频上都更好（训练数据更多样），无法把「方言适应」和「模型更强」
分开。20 句固定种子版本里甚至出现了相反的顺序（原版 LLM 的相对改善比 SFT 更大）。
因此这条只作**辅助观察**，不作为"有口音"的证据。

## 3. 普通话能力保留

1. **ASR**：普通话 CER 0.0384 → 0.0340，不退化反降。
2. **TTS**：SFT 模型读 4 句普通话文本，两个识别器 CER 都是 **0.0000**。
3. **服务层**：`mandarin` 声音直接走原版模型，SFT 权重完全不参与，结构上保证原能力。

## 4. 失败的指标

### 4.1 方言分类器（准确率 0.567）

思路：KeSpeech 同一批录制里既有西南官话也有普通话，训练二分类器，看合成音频更像哪边。

做法：MFCC 统计特征 + 逻辑回归，按说话人分组做 GroupKFold（防止同一说话人的录音同时出现在
训练和验证里）。

结果：**说话人无关交叉验证准确率只有 0.567**（随机基线 0.5）。不做说话人分组时能到 0.9+，
但那是在识别「录音通道/说话人」，不是识别方言。

结论：不可用，已从评测删除。脚本保留在 `src/train_clf.py` / `src/check_clf.py` 作为失败记录。

### 4.2 s/sh 平翘舌声学检验（不可用）

思路：四川话把 zh/ch/sh 并入 z/c/s，「四」(si) 和「十」(shi) 变得几乎一样；普通话里
翘舌音的频谱重心明显更低。用 CTC 强制对齐拿到每个字的起始帧，测擦音段的频谱重心，
比较 `重心(s) − 重心(sh)` 的差距。

结果（`results/minshi_failed.json`）：

| 音频 | 重心(s) | 重心(sh) | 差距 |
|---|---|---|---|
| 真人四川话（18 条） | 3555 Hz | 3422 Hz | +133 Hz |
| 真人普通话（13 条） | 3597 Hz | 3530 Hz | +67 Hz |
| SFT 合成（3 条绕口令） | 3602 Hz | 3570 Hz | +32 Hz |
| 原版合成（3 条绕口令） | 3339 Hz | 3682 Hz | −343 Hz |

失败原因有两条：

1. **对齐粒度太粗**。SenseVoice 的 CTC 帧长 56 ms，擦音本身只有 60–100 ms，
   起始点量化误差足以把窗口推进元音里，元音能量盖掉擦音差异。真人普通话的差距（+67 Hz）
   反而比真人四川话（+133 Hz）还小，与语言学预期相反，说明测量本身不可信。
2. **绕口令本身把模型考倒了**。SFT 模型在「四是四，十是十」这种高重复文本上出现明显
   重复/漏字（回读为「四是四四是四四四是四四四四是四」），音频不可用于声学测量。

结论：不可用。要做可靠的平翘舌检验，需要字级边界精确到 10 ms 的强制对齐（如 Kaldi/MFA），
本仓库没有这个工具链。**不做没有把握的结论。**

## 5. 踩过的坑：ITN 口径不一致造成的假提升

第一轮 ASR 微调报出「西南官话 0.1394 → 0.1258，普通话 0.0685 → 0.0449」，看起来很好。
复核时发现基线用 `use_itn=True`、微调版用 `use_itn=False`：基线把数字读成汉字
（「七千多种」→「7000多种」），参考文本是汉字，于是基线凭空多出一批错误。

统一到 `use_itn=False` 后，基线真实值是 0.1078 / 0.0384，第一轮微调（0.1258 / 0.0449）
其实**比基线更差**。整个第一轮结论作废，重训第二轮（更低学习率 4e-6、干净扩充数据、
正确的 `<|NEUTRAL|>` 情感 token）才拿到 §1 的结果。

教训：**任何对比评测，两条链路的口径必须逐字对齐**，尤其是解码后处理这种"看起来无关"的开关。

## 6. 结论

| 结论 | 证据强度 |
|---|---|
| ASR 听得懂川话，且普通话不退化 | **强**：跨说话人留出集，双向 CER 都降 |
| TTS 能正确读出川话文本（原版读错 25% 的字） | **强**：同一句文本三方对照，0% vs 25% |
| TTS 音色是目标说话人 | **中强**：campplus 余弦 0.678 |
| TTS 口音强度对标真人 | **中**：普通话 ASR 偏离量 0.0748 ≈ 真人 0.0767 |
| 「像不像四川人说话」 | **需人耳验收**：这是主观判断，本仓库不谎称有客观答案 |

最终验收请直接听 `samples/` 下的音频，并与 `samples/base_*` 对照。
