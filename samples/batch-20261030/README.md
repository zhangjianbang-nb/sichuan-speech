# 四川话合成试听包（2026-10-30）

12 段音频，全部由训练机 `192.168.3.178:8100` 现场合成（GPU1，模型是 9.12 小时川话语料
微调的 CosyVoice2-0.5B）。每段再用两个识别器回读：`ft` = 川话微调 SenseVoice，
`base` = 原版 SenseVoiceSmall。两个都 0 错 = 模型确实读对了。

**先听 `all.wav`**（12 句连播，段间 0.35 秒静音），再挑单句细听。

## 声音说明

| 声音 | 是什么 |
|---|---|
| `sichuan`（01–08） | 微调模型 + 成都女声说话人向量，主力声音，不需要提示音频 |
| `sichuan_avg`（09–10） | 微调模型 + 2233 条川话说话人向量均值（平均音色） |
| `sichuan_zeroshot`（11） | 原版模型 + 川话提示音零样本克隆，对照用 |
| `mandarin`（12） | 原版模型普通话女声，用来确认普通话能力没丢 |

## 三个已知短板（不藏着）

1. **`切`（川话「去」）被读成普通话的 qù**。4 次采样里 3 次读成「去」，1 次读到「切」
   （但同一句把「火锅」读成「喝锅」）。这是方言词按普通话读音念，不是错字，但口音上
   不够地道。
2. **`收摊摊` 这类叠词名词不稳**。4 次采样分别读到「说太摊儿」「说摊摊儿」「收海滩儿」
   「收胎始」——首字和叠词都容易崩。这次挑到的最好一版是「收摊儿」（erhua 形式，
   语义没错，但和原文叠词不同）。这是训练语料里叠词样本太少的直接后果。
3. **零样本克隆（11）不稳定**，会把「走嘛」重复成「周末周末」。这个声音本来就只做对照，
   主力用 `sichuan`。

## 关于 best-of-5

TTS 采样是随机的，同一个模型同一句话，重采样会得到不同读音。服务端现在默认合成 5 个
候选，用川话 ASR 回读算 CER，取最好的一个（`n_samples` 参数可调 1–5）。

实测「归一」这个词的首采正确率：`sichuan` 2/8、`sichuan_avg` 3/8。所以 best-of-5
大约能把成功率抬到 76%–90%，但**不能根治**——根治需要更多含这个词的语料。

## 复现

```bash
curl -X POST http://192.168.3.178:8100/tts \
  -F "text=今天天气好安逸哦，我们出去耍一哈嘛。" -F "voice=sichuan" -F "n_samples=5" -o out.wav
curl -X POST http://192.168.3.178:8100/asr -F "file=@out.wav"            # 川话识别器
curl -X POST http://192.168.3.178:8100/asr -F "file=@out.wav" -F "model=base"  # 普通话识别器
```
